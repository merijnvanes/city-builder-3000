# CIVIC 3000 implementation contract
Original browser city builder inspired by classic isometric games. No copyrighted assets. Vanilla JS modules, Canvas 2D rendering, Vite. All files in /Users/merijnvanes/CodeProjects/civic3000.

## Simulation: sim.js
Export TOOLS array of {id,label,cost,description,shortcut}; ids inspect,road,residential,commercial,industrial,park,power,water,police,fire,bulldoze.
Export createCity(seed=42,starter=true), tick(city), place(city,x,y,tool) returning {ok,message}, getStats(city), inspectTile(city,x,y), serialize(city) returning string, deserialize(string) validated returns city or throws.
city: {size:40,tiles:Array flat row major, money:50000, month:0, tax:9, population, happiness, demand:{residential,commercial,industrial}, history:[], seed, revision:0}. tile: {x,y,terrain:'grass'|'water'|'sand',type:'empty'|toolId,level:0..4,variant:number 0..1,powered:boolean,watered:boolean,roadAccess:boolean}. Terrain river at x roughly 28..32, parkland elsewhere. Starter true should generate an attractive substantial small city around x=12,y=18 with roads on x=8,14,20 and y=10,16,22,28; blocks zoned residential/commercial/industrial populated level1..4, utilities. Leave plenty of expansion land. Starter false empty same terrain. Road over water allowed bridge. tick monthly economy growth/service calculation, update revision. getStats returns {population,money,happiness,income,expenses,balance,power,water,jobs,demand:{residential,commercial,industrial},date:string,advice:string}. power/water percent 0..100. inspectTile returns {title,description,details:array of strings}. Helpers no DOM.

## UI: ui.js, style.css, index.html
Export mountUI(actions) => {update(city,stats),notify(message),setTool(id),setSelection(info),setOverlay(id)}. actions: selectTool(id),setSpeed(n:0|1|2|3),setTax(n),save(),load(),newCity(),setOverlay(id:'none'|'power'|'water'|'landvalue'),zoom(delta),home(),toggleDay(). Main will call mountUI. HTML canvas #city-canvas inside #viewport (position absolute fullscreen); #app for UI. Import /src/main.js in HTML. UI must allow canvas interactions through empty space. Beautiful restrained warm cream/forest green contemporary city-planning workstation; header logo CIVIC / 3000, top metrics, floating left tool palette, right city stats/demand/advisor panel, bottom date/speed/tool info. Original inline SVG icons. Help controls, city reset confirmation, tax slider. Responsive <800 panels condensed. Budget optional modal. No external fonts/resources. UI owns markup only, no sim loop. update called every sim tick. ui can import TOOLS from './sim.js'.

## Renderer/main owned by parent
src/renderer.js and src/main.js parent owns. Renderer class renders tiles in isometric projection with buildings, roads, trees, animated cars/water, hover placement preview, day/night, pan/zoom. Main orchestrates state, sim ticks and UI. Node tests owned by third worker.
